# 둥지

커플 둘이 함께 꾸미고 돌보는 작은 방이에요. 여러 커플이 가입해서 서로의 방에 놀러 가요. 한 Cloudflare Worker 가 화면과 API 를 함께 내고(`dungji.choigonyok.com`), 무료 플랜 하나로 돌아가요.

jarvis 콘솔의 일정 칸에 있는 `둥지` 화면이 이 서비스를 프레임으로 띄워요. 콘솔의 운영자와 손님은 비밀번호 없이 들어와요.

1. 콘솔(`web/src/app/api/nest/ticket`)이 지금 사람의 자리(owner·guest)를 1분짜리 입장권에 서명해요.
2. 둥지(`/api/sso/jarvis`)가 서명을 확인하고 그 자리에 이어 둔 계정으로 들여보내요.
3. 처음 온 자리는 계정을 만들고, 둘은 같은 둥지에 살아요. 먼저 온 쪽이 둥지를 짓고, 나중에 온 쪽이 들어가요.
4. 이름은 처음 들어온 화면이 물어요. 그래서 설정이나 저장소에는 실제 이름이 없어요.

입장권은 한 번만 쓰여요. 프레임은 콘솔의 루트 레이아웃에 살아 있어서 다른 탭에 다녀와도 통화가 이어져요(`web/src/components/nest/host.tsx`).

## 할 수 있는 것

| 요청 | 구현 |
| --- | --- |
| 커플 미니홈피 | 둥지 하나에 둘이 살아요. 먼저 만든 사람이 초대 코드(6자)를 보내면 상대가 같은 둥지로 들어와요. 둥지에는 나무 명패(이름), 함께한 날 수, 한 줄 소개, 오늘·전체 방문 수, 비스듬히 내려다본 방이 있어요. 방은 실제 시각을 따라 새벽·낮·저녁·밤 하늘로 바뀌고, 밤에는 스탠드에 불이 켜져요. |
| 이웃 방문·방명록 | 이웃 탭에서 둥지나 사람 이름으로 찾거나 '아무 둥지나'로 놀러 가요. 놀러 가면 방이 보이고, 방문 수가 하루 한 번 올라요. 방명록에 글을 남길 수 있고, 비밀글은 쓴 사람과 그 둥지의 둘만 봐요. 주인은 답글을 달고 지울 수 있어요. 우리 둥지에 다녀간 이웃에게 답방 갈 수 있어요. |
| 커플일기 | 하루에 한 사람이 한 편을 써서 같은 날의 두 편을 나란히 봐요. 날씨나 기분 표시와 댓글을 달 수 있고, 달력의 점으로 누가 쓴 날인지 보여요. 둘만 볼 수 있어요. |
| 청소 | 세 시간마다 먼지(먼지 뭉치, 부스러기, 얼룩, 휴지, 양말, 낙엽)가 하나씩, 열두 개까지 쌓여요. 눌러서 치워요. 여덟 개가 넘으면 화분이 절반 속도로 자라고, 열 개가 넘으면 날파리가 날아요. 놀러 온 이웃도 하루 세 개까지 치워 줄 수 있어요. 키 큰 가구에 가려지는 칸에는 먼지가 생기지 않고, 가구를 옮겨 가려진 먼지는 가구 위에 표시가 떠요. |
| 창고 | 기본 4칸이고 깃털을 내고 한 칸씩 넓혀요(다섯째 80, 여섯째 160 …, 12칸까지). 산 물건은 창고로 가고, 창고가 차면 방의 빈자리에 바로 놓여요. 창고에 든 화분과 어항은 꺼낼 때까지 시간이 멈춰요. 창고에서 반값에 팔 수 있어요. |
| 화분·어항 | 화분 다섯 가지(튤립, 해바라기, 몬스테라, 선인장, 방울토마토)는 물이 있는 동안 다섯 단계로 자라요. 다 자라면 꽃이나 열매를 거둬 깃털을 받고, 마른 지 하루가 지나면 시들어요. 어항 두 가지(3마리, 6마리)에 물고기 다섯 종을 키워요. 먹이와 물 갈기를 하고, 이름을 짓고, 다 자라면 커져요. 오래 굶기거나 물이 아주 탁하면 기운이 없어져요(죽지는 않아요). |
| 음성통화 | 둘 다 둥지를 열어 두면 이름 옆에 불이 켜지고 '통화' 버튼이 살아나요. 브라우저에 들어 있는 WebRTC(오픈소스 libwebrtc)로 두 폰이 직접 소리를 주고받아요. 연결에 필요한 말(SDP, ICE)만 둥지의 Durable Object 가 건네줘요. 유료 통화 SDK 는 쓰지 않아요. |

깃털은 둘이 함께 쓰는 돈이에요. 처음 300개로 시작하고 아래처럼 모여요(`shared/rules.ts` 의 `REWARD`, `LIMIT`).

- 그날 처음 들어오기 20, 그날 첫 일기 15 (한 사람마다)
- 우리 방 청소 3, 이웃 방 청소 2 (그 방에서 하루 세 개까지)
- 이웃 방명록 5 (하루 세 번까지)
- 물 주기 2, 먹이 1, 물 갈기 3
- 거두기 40~70

이름과 그림은 모두 새로 만들었어요. 싸이월드의 이름, 도토리, 미니미, 화면 모양은 쓰지 않아요.

## 구조

```
shared/    화면과 서버가 같이 쓰는 것: 상점 목록(catalog), 규칙(rules: 먼지·화분·어항·배치), 응답 모양(api), 좌표(iso)
worker/    Cloudflare Worker: Hono API(index), 로그인(auth), 시간 흐르기와 화면 모양(home), 실시간 통로(live, Durable Object)
src/       React 화면: 방 그림(room/), 쪽(pages/), 실시간·통화·알림(lib/)
migrations D1 표
tests/     규칙 단위 시험(vitest)
e2e/       로컬 Worker 를 상대로 한 API 시험, 화면 조작 시험, 화면 촬영
```

- **시간이 흐르는 값:** 먼지, 물, 배부름, 맑기를 매번 저장하지 않아요. 마지막으로 잰 값과 그 시각을 두고, 둥지를 읽을 때 지금까지 흐른 만큼 계산해요(`tick`). 쓰기는 조건부(`WHERE state = 이전 값`)라 동시에 들어온 요청이 서로 덮지 않아요. 먼지는 '세 시간 칸'마다 자리가 정해져 있어 두 요청이 동시에 계산해도 하나만 생겨요.
- **깃털과 창고 칸:** D1 이 막아요. `coins >= 0` CHECK 와 창고 칸 수 트리거가 있어서, 모자라면 같이 묶인 쓰기 전체가 취소돼요. 한 둥지에 셋째가 들어오는 것도 트리거가 막아요.
- **로그인:** 비밀번호는 브라우저가 PBKDF2-SHA256 60만 번으로 먼저 다진 값만 보내요. 서버는 거기에 사람마다 다른 소금을 쳐 SHA-256 으로 한 번 더 다져 둬요. 무거운 계산은 폰이 하고 Worker(무료 플랜 CPU 10ms)는 비교만 해요. 같은 아이디로 15분에 열 번 틀리면 잠시 막아요. 한 주소에서 하루 스무 번 넘게 가입을 시도하면 막아요(초대 코드 맞히기 방지). 세션은 HttpOnly 쿠키예요. 쓰기 요청은 우리 화면만 붙이는 `x-dungji` 머리글이 있어야 받아요.
- **통화가 안 이어지는 망:** 두 폰 중 한쪽이 대칭 NAT(일부 회사·학교 와이파이, 일부 LTE)면 STUN 만으로는 안 이어질 수 있어요. 그럴 때는 TURN 을 붙여요. Cloudflare Realtime TURN 키(`CF_TURN_KEY_ID`, `CF_TURN_KEY_TOKEN`)를 넣거나, 직접 띄운 오픈소스 coturn(`TURN_URLS`, `TURN_USERNAME`, `TURN_CREDENTIAL`)을 넣으면 `/api/call/ice` 가 함께 내줘요.
- **한계:** 웹 앱이라 폰이 잠들거나 다른 앱으로 가면 실시간 통로가 끊겨요. 그래서 둘 다 둥지 화면을 열어 둔 동안에만 전화를 받을 수 있어요(푸시로 깨우는 전화는 없어요).

## 로컬에서

```sh
npm install
npx wrangler d1 migrations apply dungji --local
npm run build                 # dist/ 를 만든다(Worker 가 이것을 낸다)
npx wrangler dev --port 8788  # http://127.0.0.1:8788
npm run dev                   # 화면만 고칠 때: http://localhost:5180 (API 는 8788 로)
```

## 시험

```sh
# .dev.vars 에 JARVIS_SSO_SECRET=local-test-secret-for-dungji (시험이 쓰는 값)
npm test                                   # 규칙 단위 시험
npm run check                              # 타입
# 아래는 wrangler dev 를 --persist-to .wrangler-test 로 띄운 뒤
node --experimental-sqlite e2e/api.mjs     # API 96가지(jarvis 입장권 포함)
node --experimental-sqlite e2e/flow.mjs    # 화면 조작 33가지(통화 포함, 크롬). 끝에 webkit 을 주면 사파리 엔진으로
node --experimental-sqlite e2e/ui.mjs      # 폰·패드·컴퓨터, 낮·밤, 밝은·어두운 화면 촬영 → e2e/shots
# 콘솔 안의 둥지: 로컬 콘솔을 DUNGJI_URL=http://localhost:8788 과 같은 비밀로 띄운 뒤
JARVIS=http://localhost:3301 node --experimental-sqlite e2e/jarvis.mjs
```

시간이 지나야 생기는 상태(먼지, 마른 화분, 배고픈 물고기)는 시험이 로컬 D1 파일을 직접 고쳐 앞당겨요. 통화 시험은 크롬의 가짜 마이크로 두 창을 실제로 이어서, 상대 소리 트랙이 재생되는지까지 봐요.

## 배포

아직 배포하지 않았어요. 순서는 jarvis 의 [DEPLOY.md](../DEPLOY.md) '둥지'에 있어요. D1 을 만들고, 표를 올리고, 두 Worker 에 같은 비밀을 넣고, 둥지를 배포한 뒤 콘솔을 배포해요.
