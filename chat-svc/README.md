# chat-svc

**무엇을 말했는지만** 여기 있습니다. 라이브 SSE 스트림과 진행 상태는 agent 에
남아 있습니다.

## 경계

캘린더와 같은 방식입니다.

| 있는 곳 | 무엇 | 왜 |
|---|---|---|
| agent | SSE 스트림, "턴이 진행 중인가", Claude Code 세션 | 재시작을 넘겨 살아남지 않는 것이 의도다. 방금 시작한 프로세스는 턴 중간에 있지 않다 |
| chat-svc | 대화 기록 | 잃으면 운영자가 알아차리는 것 |

**제안 저장소는 옮기지 않았습니다.** 제안은 승인 게이트의 다른 반쪽이고,
결정이 날 때까지 반환하지 않는 MCP 핸들러와 한 몸입니다. 그 이동은 저장소를
옮기는 것과 다른 결정이라 여기에 끼워 넣지 않았습니다.

그래서 `turns.proposal_id` 에는 외래키가 없습니다
([017](../db/migrations/017_turns_soft_proposal_ref.sql)). 조인할 수 있는 키가
아니라 가리키는 값입니다 — 제약을 남겨두면 카드가 열린 턴을 저장하는 것이 제안
테이블이 비어 있다는 이유로 실패하고, 그 실패는 대화가 화면에 안 나타나는
것으로만 드러납니다. 제안을 Postgres 로 옮기면 그때 다시 걸면 됩니다.

## API

| 메서드 | 경로 | 하는 일 |
|---|---|---|
| GET | `/health` | Postgres 를 ping 합니다. 토큰 불필요 |
| GET | `/turns` | 대화 전체, 오래된 것부터 |
| POST | `/turns` | 한 턴 추가. id 와 시각은 서비스가 발급 |

`/turns` 에 페이지네이션이 없습니다. 콘솔은 열릴 때 스레드 전체를 그리고 —
그게 이 제품입니다, 하나의 긴 1:1 대화 — 200턴에서 조용히 끊기는 기록은 과거를
잃어버린 것처럼 읽힙니다. 느려지면 UI 가 요청하는 창을 만드는 것이 답이고,
서비스가 말없이 씌우는 상한이 아닙니다.

## 시각이 두 개인 이유

`at` 은 날짜 없는 벽시계("15:04")입니다. 콘솔이 그대로 찍는 값이라 바꾸지
않았습니다.

`atIso` 는 새로 추가한 전체 타임스탬프입니다. 기록 화면이 지금은 **id 에 박힌
epoch 를 파싱해서** 날짜를 복원하고 있는데([web/src/lib/ledger.ts](../web/src/lib/ledger.ts)
의 `raisedAt`), 그 우회가 기대던 것이 이 필드로 대체될 수 있습니다. 콘솔이 읽는
필드를 바꾸는 것은 UI 결정이라 여기서 하지 않고, 값만 옆에 둡니다.

벽시계는 Postgres 가 `to_char(at at time zone $1, 'HH24:MI')` 로 만듭니다.
시간대를 질의에 넘기므로 컨테이너의 `TZ` 설정에 의존하지 않습니다.

## 저장 실패가 대화를 지우지 않습니다

턴은 이미 일어났습니다. 쓸 수 없었다는 이유로 화면에 보여주지 않으면 두 번
잃습니다. 에이전트는 저장이 실패해도 SSE 로 발행하고(로컬 id 를 붙여서 —
id 없는 프레임은 클라이언트의 upsert 를 깨뜨립니다), 오류를 로그에 남깁니다.
그 턴은 새로고침하면 사라집니다. 파일 저장소 시절과 같은 거래입니다.

## 기존 대화 옮기기

```bash
docker compose --profile import run --rm chat-import
```

**여러 번 돌리면 대화가 중복됩니다.** 캘린더·운동과 다른 점입니다: 턴에는
자연키가 없어서 — 같은 사람이 같은 말을 두 번 할 수 있습니다 — 멱등하게 만들
방법이 없습니다. 그래서 이미 턴이 있으면 멈추고, 정말 덧붙이려면
`FORCE=true` 가 필요합니다.

**알려진 손실**: 옮긴 대화의 시각은 옮긴 시점이 됩니다. 원본의 `at` 이 날짜
없는 벽시계라서 복원할 수 있는 날짜가 애초에 없습니다. 대화의 **순서는**
보존됩니다.

## 검증한 것

- 실제 `thread.json` 109턴이 전부 옮겨지고, 순서와 제안 참조 14개가 보존됨
- 두 번째 실행이 멈춤 ("이미 109개의 턴이 있습니다")
- 존재하지 않는 제안 id 를 가진 턴이 저장됨 (외래키가 떨어진 것 확인)
- 내용 없는 턴은 400
- `at` 이 KST 벽시계, `atIso` 가 전체 타임스탬프
- 토큰 없는 요청은 401
- agent 의 `/thread` 가 이 서비스에서 109턴을 읽어옴
- 에이전트 테스트 전체 통과 — 대화 테스트는 가짜 서비스로 Postgres 없이 돌고,
  서비스가 죽었을 때도 턴이 발행되는 것과 진행 상태가 저장되지 않는 것을
  새로 확인합니다
