# assets-svc

업비트와 한국투자증권을 읽는 유일한 자리입니다. 읽기 전용 — 잔고와 시세뿐,
주문은 없습니다.

## 왜 따로 있나

**키 때문입니다.** 이 키들은 주문을 낼 수 있습니다. 브라우저에 HTML 을 내주는
Next.js 프로세스의 환경변수로 있을 이유가 없습니다. 읽기 전용으로만 쓰는 건
코드의 약속이고, 키에 붙은 권한은 그대로입니다.

분리 후 웹 컨테이너에는 `UPBIT_*` · `KIS_*` 가 아예 없습니다.

## 왜 Go 가 아닌가

업비트 JWT 서명, KIS OAuth 토큰 재사용, 해외 종목 거래소 코드 탐색, 과거 종가
페이징이 이미 TypeScript 로 돌고 있었습니다. 그 코드에는 어렵게 얻은 예외
처리가 주석까지 남아 있습니다 — 상장 안 된 에어드랍 토큰 하나가 배치 시세
요청 **전체**를 404 로 만든다는 것, KO 가 NAS 로 물으면 빈 응답이 온다는 것,
KIS 가 거래소 코드에 따라 같은 보유를 중복해 돌려준다는 것.

이걸 Go 로 다시 쓰는 것은 잘 돌던 연동을 깨뜨릴 위험만 삽니다. 디렉터리와
이미지가 분리되는 목적은 그대로 달성됩니다.

`venues.ts` 와 `change.ts` 는 웹에서 **주석까지 그대로** 옮겼습니다. 바꾼 것은
두 곳입니다.

- `import "server-only"` 제거 (Next.js 전용 패키지)
- `fetch(..., { cache: "no-store" })` 의 `cache` 제거. 그건 Next 가 fetch 를
  감싸 캐시하는 것을 끄기 위한 것이었고, Node 의 fetch 는 애초에 캐시하지
  않습니다. 신선도는 30초 TTL 이 관리합니다.

## API

| 메서드 | 경로 | 하는 일 |
|---|---|---|
| GET | `/health` | 살아있는지 + 데이터베이스 상태. 토큰 불필요 |
| GET | `/portfolio` | 보유·총액·기간별 변동·곡선 |
| GET | `/history?days=90` | 기록된 일별 총액 (스냅샷) |

`/health` 외에는 `API_TOKEN` 베어러가 필요합니다.

**데이터베이스는 필수가 아닙니다.** 증권사가 현재 보유의 원천이고, 기간별
변동은 과거 종가로 현재 바스켓을 다시 매겨 계산합니다. `DATABASE_URL` 이
없어도 `/portfolio` 는 답합니다 — 스냅샷만 남지 않습니다. 그래서 `/health` 는
데이터베이스가 없어도 200 이고, 상태는 따로 알려줍니다.

## 30초 TTL

두 증권사 모두 레이트 리밋이 있고, 과거 종가를 걸어 올라가는 데 왕복이 열
번을 넘습니다. 한 번 만드는 데 수 초가 걸립니다. 탭 두 개가 동시에 열렸다고
그 값을 두 번 치를 이유가 없고, 자산 화면의 숫자가 30초보다 신선할 필요도
없습니다. 동시에 들어온 요청은 진행 중인 계산 하나를 같이 기다립니다.

## 스냅샷

`/portfolio` 를 만들 때마다 오늘의 스냅샷을 곁일로 저장합니다(하루 한 장,
같은 날은 덮어씀). 실패해도 자산 조회는 그대로 답합니다.

스냅샷이 답하는 것은 **화면의 곡선과 다른 질문**입니다. 곡선은 "지금 들고 있는
것이 과거에 얼마였나"이고 — 입출금을 수익률로 착각하지 않는 장점이 있습니다 —
스냅샷은 "그때 실제로 무엇을 들고 있었나"입니다. 서로를 대체하지 않아서 둘 다
둡니다. 지금 화면은 스냅샷을 쓰지 않습니다.

## 개발 중 따로 띄우기

```bash
cd assets-svc && npm install && npx tsc
DATABASE_URL='postgres://jarvis:<암호>@127.0.0.1:5432/jarvis?sslmode=disable' \
  PORT=8092 API_TOKEN=<토큰> \
  UPBIT_ACCESS_KEY=... KIS_APP_KEY=... node dist/index.js
```

## 검증한 것

실제 키로 컨테이너에서 확인했습니다.

- 보유 종목(해외주식·코인)의 총액·원가·수익률·USDKRW 가 나옴
- 1일 / 1개월 / 1년 변동과 곡선이 나옴
- 1년 창에서 상장 1년이 안 된 종목이 `missing` 으로 이름이 남음 — 그만큼 거래 이력이
  없는 종목을 오늘 가격으로 평균에 넣어 "변동 없음"으로 보고하지 않는다는
  기존 설계가 그대로 동작합니다
- 스냅샷이 하루 한 장으로 유지됨 (여러 번 조회해도 행 1개, 보유 3개)
- 토큰 없는 요청은 401, `/health` 는 통과
- 웹 컨테이너에 `UPBIT_*` · `KIS_*` 가 남아 있지 않음

## 고친 것

`/history` 가 9월 26일 스냅샷을 25일로 보고했습니다. node-postgres 는 `date`
를 **로컬 자정**의 JS `Date` 로 주고, 그것을 `toISOString()` 으로 찍으면 UTC
로 변환되어 KST 자정이 전날 15시가 됩니다. Postgres 가 `to_char` 로 문자열을
만들게 해서 왕복 자체를 없앴습니다.
