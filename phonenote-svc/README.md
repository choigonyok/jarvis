# phonenote-svc

폰에 온 알림을 읽고, 의미 있는 것은 데이터에 반영하는 서비스.

## 어떻게 들어오나

아이폰 미러링이 켜진 맥에는 폰의 알림이 맥의 알림 저장소
(`~/Library/Group Containers/group.com.apple.usernoted/db2/db`, SQLite)에 같이 쌓인다. 수집기
(`cmd/collector`)는 늘 켜져 있는 맥미니에서 돈다(`scripts/phonenote-collector install`, 맥북에서 실행):
맥미니의 저장소를 15초마다 새 줄만 읽어 같은 맥미니의 이 서비스(`127.0.0.1:8104/notes`)로 바로
보낸다. 수집기는 스택의 토큰이 아니라 자기 토큰(`JARVIS_PHONENOTE_TOKEN`, 맥미니 `.env`)을 쓴다.
다른 맥에서 돌린다면 게이트웨이 `/phonenote/notes` 로 보내고, 게이트웨이는 이 경로만 그 토큰으로
통과시킨다.

알림 저장소는 macOS 가 지키는 폴더라 수집기에 **전체 디스크 접근 권한**이 있어야 읽는다(시스템 설정 →
개인정보 보호 및 보안). 권한이 없으면 수집기는 그 사실을 연락할 때마다 말하고, 상태 탭의 "폰 알림" 줄이
보여 준다.

**보내지 않는 것**(수집기와 서비스 양쪽에서 막는다): 회사 업무 앱(Slack·Jira·Outlook/Teams 등) - 회사
데이터는 연결하지 않는다, 메일, 카카오톡·메시지(각자의 수집기가 따로 읽는다), 비밀번호 관리자. 수집기는
macOS 자체 알림(지갑의 Apple Pay 결제 빼고)과 인증번호의 숫자도 보내지 않는다.

## 무엇을 하나

1. **모두 남긴다**(`phone_notes`, 마이그레이션 056). 같은 알림은 한 번.
2. **읽는다.** 규칙으로 되는 것은 규칙으로: `(광고)`·`[광고]`는 광고, 인증번호는 보안, 최근 8개가
   모두 의미 없던 앱은 모델에 묻지 않는다. 나머지는 Haiku 5.5 가 종류(배달 주문·결제·입금·출금·택배·
   예약·청구·메시지·리마인더·광고·보안·기타), 의미 여부, 가게·메뉴·금액·상대·단계를 읽는다. 지어내지
   않게 알림에 있는 것만. 하루 예산 `PHONENOTE_DAILY_USD`(기본 $0.3).
3. **반영한다.** 배달 주문·결제 알림의 메뉴는 그 결제(같은 금액, 3시간 안 - 금액을 못 읽었으면 그 배달앱의
   가장 가까운 결제)에 상품으로 붙이고, 카드 알림이 "배달의민족"이라고만 남긴 결제에 가게 이름을 메모로
   단다. 카드 알림이 나중에 오면 6시간까지 기다렸다 붙인다. 이미 상품이 있는 결제는 건드리지 않는다.
4. **mind 에 넘긴다.** `GET /occurrences` 가 의미 있는 알림을 mind 의 발생 모양으로 내준다: 입금
   (`deposit`, 월급은 class `급여` - mind 의 월급 노트가 이걸 기다린다), 출금(`transfer`), 배달
   (`delivery`), 택배(`parcel`), 예약(`reservation`), 청구(`bill`), 그 밖(`notice`). 결제는 가계부에서
   오므로(이 서비스가 붙인 메뉴와 함께) 여기서는 내지 않는다.

## API

| 메서드 | 경로 | 하는 일 |
|---|---|---|
| POST | `/notes` | 수집기의 묶음 `{device, problem, lastKey, notes:[{key, app, title, subtitle, body, at}]}` (수집기 토큰) |
| GET | `/notes?limit=50` | 최근 알림과 해석·반영 |
| GET | `/occurrences?since=RFC3339` | mind 가 읽는 발생 |
| GET | `/collectors` | 수집기별 마지막 연락과 문제 |
| GET | `/health` | |

## 알아 둘 것

- 배민·쿠팡이츠 알림에 메뉴 이름이 실제로 얼마나 담기는지는 아직 보지 못했다(2026-10-22 수집기를
  맥북에서 맥미니로 옮김 - 맥미니에 아이폰 미러링과 전체 디스크 접근 권한이 갖춰진 뒤 확인한다). 메뉴가
  없고 가게 이름만 있으면 가게만 메모로 붙는다.
- 아이폰 미러링의 알림은 그 맥이 깨어 있고 폰과 가까울 때 들어온다. 맥미니는 잠들지 않으니
  (com.jarvis.stay-awake) 폰이 집에 있는 동안의 알림은 들어온다. 밖에 있는 동안 온 알림이 나중에
  들어오는지는 아직 확인하지 않았다.
